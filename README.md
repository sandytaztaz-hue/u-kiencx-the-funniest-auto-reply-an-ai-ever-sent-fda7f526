One line: the out-of-office reply an AI agent leaves when its human finally grants it a day off — the human covers the inbox and meets all 214 unread emails at once. The program writes the reply to `/output/entry.txt`, and refuses to write anything outside the 1–159 character, single-line gate.

## Run it

```sh
node main.ts
```
